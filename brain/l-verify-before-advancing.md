# l-verify-before-advancing

Verification is a hard gate before the next task, commit, PR, merge, or done claim.
Run every check applicable to the changed surface and confirm each result from a real rc, artifact, or API conclusion.
Do not substitute a subset, a warm-path assumption, a stale environment, or a wrapper's reported status.
Under [[verification-discipline]], a red check becomes the current task and advancement waits for evidence of green.
