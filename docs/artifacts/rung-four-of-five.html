Why not start clean

The three things a rebuild would throw away are the three that took the longest to get right: the generated record type with its drift gate, the channel-check-before-null discipline inside trackers, and a container acceptance harness that runs a real agent against the published docs. All three are the parts a second attempt would rediscover slowly.

What a rebuild would fix — one verb, no aggregation, no report — is not fixed by starting over. It is fixed by rung 4.
