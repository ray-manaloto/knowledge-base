One place to read back every agent session

You already have the logs. Nothing here reads the Codex half of them.

What it is
A small app that runs on your machine. It opens the log files your agents already write, and gives you a searchable view of them.
The win
It reads Codex runs too — the half nothing here can see today. It also totals up what each run cost.
The catch
"Telemetry" here means only the numbers already sitting in those log files. It is not a pipe you can send other systems' metrics into.
Risk
Low, but it is not read-only: it builds its own index file in your home folder. Nothing is sent out by default — the one export is a separate command we would not run.

Corrected after publishing. The risk row first said it "only reads". It writes an index, and an opt-in export command exists. Both were checked in its own docs, not assumed.
