Settled rules

  • Pins move by the tool's own command; text edit only as fallback.
  • Two layers: Python does everything mechanical for free; agents do only judgment.
  • Done per tool = pin, lock, install, source pin, gates, one commit. One rebuild per run; deep re-extraction recorded as skipped.
  • Roster of eight new agents plus four reused — final knobs set after the Claude Code docs source is resynced.
