You asked one question directly. Here is the answer.

“What exactly did we test with a Claude agent following instructions from the plugin — did it actually perform a search and validate the results?”

It searched. Nothing validated the results. In the container, a fresh agent read the READMEs, installed the plugin, and ran the CLI. It hit GitHub's search API for real and got two genuine hits — pull requests #574 and #346 in openai/codex-plugin-cc.

But the gate on that output was:

jq -e '.adapter == "trackers" and (.hits | type == "array")'

That asserts the JSON has the right shape. An empty hits array passes it. Nothing checked relevance, nothing checked the links resolve, nothing compared sources — because there is only one source. The test proved the agent can invoke the tool. It never proved the tool researches anything.
