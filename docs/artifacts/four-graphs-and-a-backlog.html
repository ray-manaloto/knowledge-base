CONTEXTOne more thing worth knowing before you choose

The corpus is running on a raised ceiling.

mise run graph-size → 736.4 MiB of 1,024 MiB (72%), 287.6 MiB headroom — OK, exit 0, measured this session. But graphify's stock refusal point is 512 MiB. The graph is only readable because GRAPHIFY_MAX_GRAPH_BYTES raises it — mise.toml calls that raise a ratchet and names the durable fixes as #130 (federate) and #120 (the duplicated repo:: prefix). Both open.

Why this matters to the plan and not just to ops: “deeply extract all our large dependencies” (your item 5) makes the graph bigger. Doing it before federation walks the corpus into the ceiling that already broke it once, at 532.1 MiB on 2026-08-03.
