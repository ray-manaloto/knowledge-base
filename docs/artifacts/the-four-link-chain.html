The Four-Link Chain

Every dependency this repo uses has to agree with itself in four places. Ninety-four times. Here is where it doesn't.

The one-sentence version

A pinned tool is only really in the knowledge graph when four separate things say the same version. We measured all four for every first-level dependency: 9 never start the chain, 3 break at the second link, and 6 are cut before the last one.

What has to line up

Think of it like a library that keeps a copy of every book it recommends. The pin is the edition you told people to read. The manifest is the card in the catalogue. The clone is the physical copy on the shelf. The graph is the index at the back that lets you actually look something up.

If the catalogue card names last year's edition, you'll fetch the wrong book and never know. If there's no card at all, the book isn't in the library — you just remember owning it. And if the copy is on the shelf but was never indexed, searching finds nothing.

Why the order matters

These stages are not independent. Advancing a pin without advancing its manifest just moves the break from one link to the next, and rebuilding the graph before either is finished indexes the wrong source.

Stage 4 is the expensive one — it re-clones every pinned source and is the only stage that costs real wall clock. Stages 1–3 are cheap and reversible.

One thing that turned out not to be broken

A persisted record has been telling every session that kb-build will fail again, quoting the line [graphify] Pruned 3 node(s) from 3 deleted or excluded source file(s).

Armed directly this session: that exact line now filters to empty, while a genuine WARNING: line and a trailing-text variant both survive unfiltered. So the probe discriminates, and the recorded cause no longer reproduces — the fix landed after the record was written. The record regenerates a fresh prediction from an old failure without ever re-testing it.

This is the second stale build-failure prediction found in two rounds. The first named a template file that no longer exists.
