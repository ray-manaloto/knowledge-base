The split

A broken file can be signed off one by one. A name clash cannot — nothing in the system can accept one, so those sources can only be set aside until the tool is fixed.

Set aside

Six. Five have name clashes and no other option. One is ruff — 289 broken files, the same "checker with a pile of bad examples" shape as biome.

Sign off

Five, small enough to be worth it: seven files between them, plus two odd cases that fit categories we already accept elsewhere.

Confidence

One row was independently confirmed by a real rebuild and matched exactly. The other ten are predictions — from the same judgement the build itself uses.

What I need from you

Approve the split, or change it. Setting six aside gets a green build soonest and costs six sources; signing off more keeps them but is slower and each one needs its own justification.
