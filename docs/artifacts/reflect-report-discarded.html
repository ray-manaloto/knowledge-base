The report nobody reads

Every session already builds a full self-review of itself. Then it throws it away, one second before the session ends.

What happens
At the end of every session the project builds a complete report on what that session did by hand. All the work is already paid for.
Then
It prints two numbers and deletes the report — at the exact moment there is nobody left to read it.
The fix
Keep the file. Show it at the start of the next session, when there is a whole session's room to act on it.
Not the other fix
The plan was to hang the report off a "how full am I?" command. But that command is itself only ever run late — so the report would arrive just as tired as before.

What I need from you: pick where the report should surface — I have the question queued right after this.
