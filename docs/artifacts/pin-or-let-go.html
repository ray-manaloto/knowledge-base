the last decision in this round

Name it, or let it be changed. You can’t have both.

Writing a setting into a helper’s file makes it permanent — anyone who later asks for something different is quietly ignored. Leaving it out makes it changeable, but then the helper doesn’t guarantee what its name promises.

A Write both settings in The expensive brain and the deep thinking are locked in. Always what it says on the tin. · Nobody can ever run it cheaper, and they get no warning.
B Write neither in Both come from the project-wide default, and any caller can change them. Fully changeable. · Defaults to the cheap brain — so the name would be a lie.
C Write only the brain in The expensive model is guaranteed; how hard it thinks stays adjustable. Name kept, thinking dial free. · Its default depth is the ordinary one, not the deep one.

this is measured, not read

A live run asked for a cheaper brain than a helper’s file names. It got the file’s choice, silently, with no warning — and a second run asking for different thinking depth was overruled the same way. Both confirmed against the machine’s own recording, not the helper’s word for it.

Which one? C is my read — it is the closest thing to the “changeable default” you asked for that still keeps the name honest.
