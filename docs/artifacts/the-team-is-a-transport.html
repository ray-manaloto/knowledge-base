Which channel to build on

Three transports exist on the pinned source (rust-v0.150.1). The picture draws the one thing they differ on: where the durable state lives — a file and a session id on disk, or a live connection.

The offload rule, updated

Offload to Codex when the work is bounded by a spec you can write in full, and the result is verifiable without your context. Four amendments this round earned:

  • Never route a typed call through codex exec review (#38545).
  • Bound every dispatch externally — Codex has no per-call cap (#33294). Effort tier before, wrapper timeout during.
  • Do not spec a verification the lane's sandbox cannot run. The 2700 s watchdog kill (workspace-write has no network; the spec demanded live gh) and the #559 substitution both trace to that. MEASURED: evidence-agent-team-0828.md:141-145
  • Require a codex session id inside the typed return, and verify it — codex exec resume <id> succeeds, or the session file exists. Corrected after the fable-advisor verdict: an earlier version of this line said a self-reported executor: "codex" field would fail validation; a lane that wrote the files itself would fill that in just as plausibly, and schema enforcement under a violating reply is unmeasured. An id you can resume is an arm; a label is an attestation.
