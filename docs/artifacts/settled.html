The build order, and why links goes first

An adapter is only "done" when its cited links resolve. That made links a prerequisite for every other adapter — so it moves to the front, where it is also the cheapest thing to build.

The unimplemented lane must not go quiet

Three places record why the agy lane is a seam and not an implementation, so nobody later reads an empty branch as an oversight:

  1. a note in the plan, stating the token constraint and the evidence that weakened its value case;
  2. a GitHub issue holding the open question — does agy give a measurable recall gain over firecrawl/exa/last30days — and what would settle it;
  3. an inline comment at the seam in the code, naming the issue and saying the lane is pending research and a prototype, not forgotten.

This is the same discipline as the provisional budgets above: the point is never that a decision is final, it is that the next reader can see what was decided and on what evidence.
