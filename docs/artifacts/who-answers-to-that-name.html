Who answers to that name

The round's first instruction is “run the research through the installed plugin CLI, not the repo-local one.” Typing aggregated-research in this repo does the opposite — and the plugin's own copy currently refuses to start.

Three things answer to one name

A command name is not an identity. The shell hands it to the first directory on PATH that has a file by that name, and three different programs here are called aggregated-research.

Where the handoff and the repo disagree

The choice

The research itself is unblocked either way — one prefixed variable makes the plugin CLI run right now. What is open is whether the leak gets fixed in the plugin before the round starts, or is logged as a residual and worked around.
