the trap

“All agents in the team are equally intelligent and capable.”

That sentence is fed to the expensive model every time it starts work. It is not true here. This project quietly gives every helper a cheaper brain — which is exactly the saving you asked for.

So the expensive one decides what is safe to hand off while believing the helpers are its equals. Nothing in the tool corrects this. The instruction has to say it.

Three decisions: which thinking level the new advisor runs at, whether to switch the feature on, and whether its role file should pin the expensive model permanently or let each call choose.
