Agentsview First

You are right that it is independent, and right that it should go first. Its one blocker turned out to be already resolved — and there is exactly one thing in its way, which is a PR sitting green and unmerged.

Why it was stalled

The blocker is gone, and nobody noticed

Issue #638 §11 held agentsview back on one premise, marked UNVERIFIED and load-bearing: whether its schema stores individual tool calls with their bash command strings. Without that, it cannot detect an agent bypassing the skill → mise task → python mandate. The issue insisted a prototype run before any telemetry ticket.

That prototype is unnecessary. The official docs at the pinned tag answer it directly.

What #638 needed to knowWhat the docs say at v0.41.1
Are individual tool calls retrievable? agentsview session tool-calls <id> — “flat tool-call list” · docs/commands.md:1018
Is the full bash command text kept, or truncated? “Bash tool blocks show the full command text, including multi-line commands like heredocs that would otherwise be truncated” · docs/usage.md:673-675
Does it see agents other than Claude? “Codex tool calls receive special formatting: bash commands, …” · docs/usage.md:692
Why that third row is the whole point

kb-session-reflect already detects mandate bypasses for Claude — it caught this session’s own piped-gate calls and un-armed greps. So agentsview’s marginal value was never the detection.

It is cross-agent coverage. Codex and antigravity lanes run commands nothing here can currently see, and this session alone dispatched six codex lanes. That blind spot is the actual gap, and the docs say agentsview covers it.

The one thing in the way

PR #637 holds the file this needs

The proposal

Four steps, none of which touch the upgrade protocol

1

Land PR #637

mise run kb-land -- 637. It is green, its review receipt is current, and it was already owed from the last session. This is the only step that needs your say-so, because merging is outward-facing.

Expect the #619 misreport — cross-verify with gh pr view 637 --json state,mergedAt,mergeCommit.

2

Pin it, on a fresh branch

# mise.toml [tools] — ubi, because agentsview is NOT in mise's registry
"ubi:kenn-io/agentsview" = "0.41.1"

Plus sources/agentsview.manifest at the release tag, and a currency.toml row so it does not join the 15 dependencies nothing tracks. Then mise lock -- agentsview — scoped, never bare, or it re-solves the conda closure and drops macOS-Intel coverage 89 → 72.

One PR, small, independent of everything else in flight.

3

Probe it against a real session before building anything on it

Point it at this machine’s existing transcripts and confirm, with a control arm, that a codex lane’s bash commands are retrievable — not just Claude’s. The docs say they are; a doc is not a database.

Minutes. And it is the arm that decides whether step 4 is worth writing.

4

Write the detector as a mise task

kb_setup module + mise run kb-bypass-audit: query agentsview for tool calls across every agent, flag commands a mise task already owns, and flag output piped to a file or dropped. That is #350 / #461 / #268 finally having an instrument instead of a mandate.

The real work. Cross-agent, which nothing here can do today.

Doing this now versus after the spec

The trade

Now — recommended

  • It is genuinely independent. It shares no file with the upgrade protocol beyond one mise.toml line.
  • It measures the thing we are about to do a lot of. Six codex lanes ran this session, invisibly. The upgrade protocol will run many more.
  • It clears an owed item that has been carried across three handoffs.
  • Landing #637 also unblocks the typos/agnix minor bumps, which are owed from the same currency ask.

After — the honest case

  • It is one more thing in flight while five design questions are still open.
  • Step 4’s detector would be a second consumer of session data alongside kb-session-reflect, and nobody has decided whether they merge.
  • A new tool is a new currency obligation, and we have just measured that 15 of 33 dependencies already lack one.
