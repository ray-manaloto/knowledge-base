### Observation (not filed as a finding): "the automated sync is the right owner of its version" is wider than what the code does

- **Where:** `tests/test_tool_sync.py:320-322`.
- **What:** The docstring links eligibility to "always pin to the latest". But `tool_sync` only locks, installs and verifies the pin that is already written; it never moves the pin. The module docstring says so: "Synchronize one reviewed mise pin". The `kb-tool-sync` task description says the same (`mise.toml:1569-1571`).
- **Effect:** Being eligible means the lock and install stay consistent with the pin. It does not mean webclaw stays current with upstream.
- **Severity:** Wording only. It does not change the assertion.
