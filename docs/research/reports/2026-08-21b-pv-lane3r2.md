## MISSING

**M1 — "equal sha256 ⟹ equal git blob id" is SOUND. Removing the assert is safe.** `graphify_baseline.source_manifest` takes blob bytes from `git cat-file --batch` (`:468`, `:478`) with **no filters** — no smudge/clean, no text conversion — sets `git_object` from `ls-tree` (`:472`, `:494`) and `sha256 = hashlib.sha256(blob).hexdigest()` (`:495`), `size = len(blob)` (`:496`). A blob id hashes `"blob "+len+"\0"+content`, so equal content ⟹ equal id. Only a SHA-256 collision reaches it. **`parent_size` is safe for the same reason** — say so in the docstring, since it is currently justified by the same removed assert. Edge worth one clause: `mode` is not in the blob id, so a symlink (mode `120000`, content = target string) and a regular file with identical bytes would dedupe together; harmless here, but `DuplicateGroup` records no mode.
