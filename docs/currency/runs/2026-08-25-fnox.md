Secret values use Keeper notation such as `RECORD_UID/field/password`. - **`fnox set --from-file <path>`** ([#730](https://github.com/jdx/fnox/pull/730)) -- @jdx. Reads a secret value verbatim from a UTF-8 file without trimming, preserving trailing newlines. This fixes SSH private keys and similar `as_file` secrets losing their required final newline, which happened because `fnox set` trims stdin values and shell command substitution strips trailing newlines. The existing `echo "x" | fnox set KEY` behavior is unchanged; `--from-file` cannot be combined with a positional value.
